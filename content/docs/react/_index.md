## מה זה?

React היא הספרייה הפופולרית ביותר בעולם לבניית ממשקי משתמש, וזו הדרך שבה רוב האתרים והאפליקציות המודרניות בנויות היום בצד הלקוח. הקטגוריה מניחה שיש לכם כבר בסיס טוב ב-JavaScript וב-DOM, ובונה עליו שכבה חדשה: במקום לתפעל את הדף ידנית, לומדים לתאר איך הממשק אמור להיראות בכל רגע נתון, ו-React דואגת לעדכן אותו בפועל. מהיסודות של קומפוננטות ו-state ועד דפוסים מתקדמים כמו ניהול state גלובלי וביצועים, זו הקטגוריה שהופכת אתכם ממי שיודע JavaScript למי שיודע לבנות אפליקציות ווב אמיתיות.

## מה הולכים ללמוד

- להכיר את הרעיון המרכזי של React ואיך היא שונה מעבודה ישירה מול ה-DOM
- לבנות ממשק מקומפוננטות עצמאיות וניתנות לשימוש חוזר
- לנהל מידע משתנה בקומפוננטה בעזרת state
- להציג רשימות דינמיות ותוכן מותנה במסך
- לגשת ישירות לאלמנטים ולערכים בעזרת useRef
- להריץ פעולות בתגובה לשינויים בעזרת useEffect
- לשתף מידע בין קומפוננטות רחוקות בעזרת Context API
- לחלץ לוגיקה חוזרת לתוך Custom Hooks משלכם
- לתפוס שגיאות בממשק ולמנוע קריסה מלאה של האפליקציה עם Error Boundaries
- לבחור גישה נכונה לניהול state בכל האפליקציה
- לשפר ביצועים ולמנוע רינדורים מיותרים עם כלים כמו React.memo
- לנווט בין מסכים באפליקציה בעזרת React Router
- לחבר את האפליקציה לנתונים אמיתיים משרת
- פרויקט מסכם: בניית אפליקציית ניהול משימות מלאה עם ניתוב, Context, Custom Hooks וחיבור לשרת אמיתי

## למה זה חשוב

React היא כלי העבודה המרכזי של מפתחי Frontend כיום, ושליטה בה פותחת דלת לרוב משרות הפיתוח בשוק. מעבר לשוק העבודה, הדפוסים שנלמדים כאן - חשיבה בקומפוננטות, ניהול state, הפרדת לוגיקה ל-Hooks - הם דפוסי חשיבה שרלוונטיים גם מחוץ ל-React עצמה. מי שמשלים את הקטגוריה הזו יודע לקחת דרישה של "בואו נבנה אפליקציית ווב" ולתרגם אותה למבנה קומפוננטות ברור, יעיל ומחובר לנתונים אמיתיים.
