## מה זה?

Git הוא מערכת בקרת גרסאות שעוקבת אחרי כל שינוי בקוד לאורך זמן, ומאפשרת לחזור אחורה, להשוות גרסאות ולעבוד בביטחון בלי לפחד "לשבור" משהו. GitHub הוא השירות שמארח את מאגרי ה-Git בענן ומאפשר לכמה אנשים לעבוד על אותו פרויקט בו-זמנית. בקטגוריה הזו לומדים לעבוד עם Git מקומית, לסנכרן מול GitHub, ולנהל עבודה מקבילה של כמה אנשים על אותו קוד בעזרת ענפים (branches).

## מה הולכים ללמוד

- **Git Basics (local repo)** — איך יוצרים מאגר Git מקומי ושומרים snapshots (commits) של הקוד לאורך זמן
- **Git & GitHub (remote, push/pull)** — איך מסנכרנים מאגר מקומי עם מאגר מרוחק בענן, שולחים ומושכים שינויים
- **Branches & Merge** — איך עובדים על תכונה חדשה בענף נפרד בלי לפגוע בקוד הראשי, ואיך פותרים קונפליקטים כשממזגים ענפים
- פרויקט מסכם — תרגול זרימת עבודה מלאה: מאגר מקומי → GitHub → ענף → Pull Request → מיזוג תוך פתרון קונפליקט אמיתי

## למה זה חשוב

בלי Git, כל טעות בקוד עלולה להיות בלתי הפיכה, ועבודה של כמה אנשים על אותו פרויקט הופכת לכאוס של קבצים כפולים. Git ו-GitHub הם הכלים שכל צוות פיתוח משתמש בהם, ללא יוצא מן הכלל — הם הבסיס לכל עבודה מקצועית בענף, כולל תהליכי code review, Pull Requests ו-CI/CD. שליטה טובה בכלים האלה היא לרוב הדבר הראשון שמעסיקים בודקים כבר בשלב הראיון, ולעיתים אף לפני שמסתכלים על ידע ספציפי בשפת תכנות.
