## מה זה?

JavaScript היא השפה שמריצה כמעט את כל האינטרנט - היא רצה בדפדפן, והודות ל-Node.js גם בשרת, כך שאותה שפה מלווה אתכם משורת הקוד הראשונה ועד לאפליקציית Full Stack מלאה. הקטגוריה הזו היא הבסיס של כל הקורס: React, Express וגם TypeScript נבנים ישירות על היסודות שתלמדו כאן. המטרה היא לא רק להכיר תחביר, אלא להבין איך JavaScript "חושבת" - משתנים, פונקציות, מבני נתונים, ובעיקר איך היא מתמודדת עם קוד א-סינכרוני, שהוא לב ליבה של תכנות ווב מודרני.

## מה הולכים ללמוד

- להכיר את התחביר הבסיסי של JavaScript ואת הסביבה שבה היא רצה
- לעבוד עם משתנים ולהבין את ההבדלים ביניהם
- לקלוט קלט ולהציג פלט בתוכנית
- לשלוט בזרימת התוכנית עם תנאים ולולאות
- לכתוב פונקציות ולהבין איך מעבירים להן מידע ומחזירים ממנו תוצאה
- לעבד ולעצב טקסט בעזרת מתודות מחרוזות
- לאחסן ולנהל אוספי נתונים במערכים
- לייצג ישויות מהעולם האמיתי באמצעות אובייקטים
- לסנן, למפות ולצבור נתונים במערכים בעזרת מתודות מערך
- לגשת למידע ולפעול על אובייקטים בעזרת מתודות אובייקט
- להבין Closures - איך פונקציה "זוכרת" את הסביבה שבה נוצרה
- לבנות אובייקטים בעזרת Factory Functions
- לפצל קוד למודולים נפרדים בעזרת ESM (import/export)
- לכתוב קוד נקי, קריא ומתוחזק
- לאתר ולתקן באגים בעזרת כלי דיבוג
- להבין מהו קוד א-סינכרוני ולמה הוא הכרחי בפיתוח ווב
- להבין את ה-Event Loop ואיך JavaScript מנהלת משימות ברקע
- לשלוף נתונים מרשת האינטרנט בעזרת Fetch API
- לעבוד עם Callbacks כדרך הבסיסית לטיפול בקוד א-סינכרוני
- לנהל קוד א-סינכרוני בצורה נקייה יותר עם Promises
- לכתוב קוד א-סינכרוני שנקרא כמו קוד סינכרוני עם async/await
- פרויקט מסכם: בניית תוכנית קטלוג ספרים בשורת הפקודה, מחולקת למודולי ESM ומתחברת ל-API אמיתי - שילוב של כל מה שנלמד בקטגוריה

## למה זה חשוב

שליטה טובה ב-JavaScript היא התנאי ההכרחי להצלחה בכל שאר חלקי הקורס - בלעדיה אי אפשר להבין באמת איך React מנהל state, איך Express מטפל בבקשות, או למה TypeScript בכלל נחוץ. מעבר לכך, זו השפה שתלוו אתכם לאורך כל הקריירה כמפתחי ווב, בצד הלקוח ובצד השרת כאחד. מי שמסיים את הקטגוריה הזו ביסודיות יודע לא רק "לכתוב קוד שעובד", אלא גם להבין למה הוא עובד - וזו בדיוק היכולת שמבדילה מפתח שמעתיק קטעי קוד ממפתח שיודע לפתור בעיות באמת.
