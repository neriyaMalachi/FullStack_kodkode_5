## דגשים להעברת השיעור

- אל תגידו "פונקציה זה ככה" לפני שהראיתם קוד משוכפל אמיתי.

- hoisting — הדגימו בפועל ש-greet() עובד לפני ההגדרה (declaration), אבל greet2() זורק שגיאה (expression).

- "שכחתי return" — כתבו פונקציה בלי return, קראו לה, הראו שהתוצאה undefined.

- Arrow function — אל תציגו את this כאן (מגיע בשיעור classes/objects בהמשך).

- Scope — השתמשו בדיאגרמת "עיגולים מקוננים" (global מבחוץ, function באמצע, block הכי פנימי).

## מושגים

- **Function (פונקציה):** בלוק קוד עם שם, מקבל קלט, מחזיר ערך. פותר את בעיית שכפול הקוד (DRY).

- **Function Declaration:** הצהרה עם function — מורמת (hoisted), ניתן לקרוא לפני שורת ההגדרה.

- **Function Expression:** פונקציה שמאוחסנת במשתנה — לא מורמת, נגישה רק אחרי שורת ההגדרה.

- **Arrow Function:** תחביר קצר () => {}; ביטוי בודד מחזיר ערך אוטומטית.

- **Parameter:** שם המשתנה שהפונקציה מצפה לקבל, כפי שמופיע בהגדרתה.

- **Argument:** הערך הממשי שמועבר לפונקציה בזמן הקריאה.

- **Default Parameter:** ערך ברירת מחדל כשארגומנט לא סופק.

- **Return / undefined:** return מחזיר ערך ועוצר את הפונקציה; בלעדיו מוחזר undefined.

- **Scope:** התחום שבו משתנה נגיש — global, function, או block.

- **Scope Chain:** פונקציה פנימית רואה משתנים של הscope החיצוני שלה, לא להפך.
