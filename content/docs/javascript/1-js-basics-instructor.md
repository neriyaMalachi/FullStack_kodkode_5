משך: 2 שעות אקדמיות (90 דקות).

מטרת השיעור: הסטודנטים יבינו למה הומצאה JavaScript (דפים סטטיים לא הספיקו), איפה היא רצה (דפדפן ו-Node.js), ומה חמשת טיפוסי הנתונים הבסיסיים והאופרטורים הבסיסיים.

בסוף השיעור הסטודנטים צריכים: להסביר במילים שלהם למה נדרשה שפה כמו JavaScript, לזהות את חמשת הטיפוסים הבסיסיים לפי `typeof`, ולהשתמש נכון באופרטור ההשוואה `===` במקום `==`.

דגש קריטי: זה השיעור הראשון בקורס. מטרתו לא לכסות את כל השפה — אלא לבנות בסיס שאליו כל שאר השיעורים יתחברו. משתנים (`let`/`const`/`var`), Scope ו-Coercion הם נושא השיעור הבא — כאן רק טיפוסים ואופרטורים.

## דגשים להעברת השיעור

- קודם הבעיה, אחר כך הפתרון — "אל תגידו 'JavaScript היא שפה ש...' לפני שהראיתם למה בכלל היינו צריכים אותה."

- אל תיכנסו ל-var/let/const בשיעור הזה — "זה נושא שלם בפני עצמו, בשיעור הבא."

- typeof null — הראו את זה כתופעה מוזרה, לא כטעות שלכם — "זו בעיה היסטורית ב-JavaScript עצמה."

- הדגישו למה `===` ולא `==` — "`==` ממיר טיפוסים לפני ההשוואה ויוצר הפתעות."

## מושגים

- **Interpreted Language (שפה מפורשת):** שפה שמורצת שורה אחר שורה ללא שלב קימפול נפרד.

- **DOM (Document Object Model):** הייצוג שה-JavaScript יכול לגשת אליו ולשנות בדף.

- **Data Type (סוג נתון):** הסיווג של ערך — string, number, boolean, null, undefined.

- **typeof:** אופרטור שמחזיר את שם הטיפוס של ערך כ-string.

- **Strict Equality (===):** השוואה שבודקת גם ערך וגם טיפוס.

## תרגיל חשיבה

- **נושא:** מה JavaScript חושבת שאתה מתכוון?

- נציג ביטויים: `"5" + 3`, `5 == "5"`, `5 === "5"`, `typeof null`.

- נבקש מהסטודנטים לנחש לפני שמריצים — ולנמק.

- **מהלך:** הצגת הביטויים, ניחוש קבוצתי, הרצה ב-console, דיון על ההבדל בין `==` ל-`===`.

- המדריך יסכם: "מהיום, כל השוואה ב-===. זה כלל בלי יוצא מן הכלל בקורס הזה."
