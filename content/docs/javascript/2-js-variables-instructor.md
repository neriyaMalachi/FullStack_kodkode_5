משך: 2 שעות אקדמיות (90 דקות).

מטרת השיעור: הסטודנטים יפנימו כלל אחד שיחסוך להם שעות של debug בעתיד — `const` ברירת המחדל, `let` כשצריך לשנות, `var` אף פעם — ויבינו למה `==` מסוכן ומה זה Scope.

בסוף השיעור הסטודנטים צריכים: לדעת מתי להשתמש ב-`const` ומתי ב-`let`, לזהות Type Coercion בקוד לפני שהוא גורם לבאג, ולהסביר למה `var` שהוכרז בתוך `if` עדיין נגיש מחוצה לו.

דגש קריטי: כל שלושת חלקי השיעור (הכרזה, המרת טיפוסים, Scope) בנויים באותה תבנית — קודם קוד שמעורר שאלה, ואז ההסבר.

## דגשים להעברת השיעור

- קודם השאלה, אחר כך התשובה — תנו לסטודנטים לנחש לפני שאתם מסבירים או מריצים.

- const לא נועל את הערך, נועל את ההפניה — ציינו זאת בקצרה, בלי להרחיב ל-Reference vs Primitive.

- Coercion — עצרו על "5" + 1 לעומת "5" - 1. שאלו: "למה פלוס מתנהג אחרת מחיסור?"

- typeof null — הראו את זה כתופעה מוזרה בשפה עצמה, לא כטעות שלכם.

- Scope — הדגימו חי: var בתוך if נגיש אחריו, let זורק שגיאה.

## מושגים

- **const:** הצהרת משתנה ב-block scope שאינה מאפשרת השמה מחדש של ההפניה.

- **let:** הצהרת משתנה ב-block scope שמאפשרת שינוי ערך.

- **var:** הצהרה ישנה ב-function scope עם Hoisting — לא בשימוש בקוד מודרני.

- **typeof:** אופרטור שמחזיר את שם הטיפוס של ערך כ-string.

- **Type Coercion:** המרה אוטומטית בין סוגי נתונים ש-JavaScript מבצעת.

- **Scope (טווח נראות):** האזור בקוד שבו משתנה נגיש.

- **Hoisting:** התנהגות שמעלה הצהרות var לראש הפונקציה.

## תרגיל חשיבה

- **נושא:** למה var "בורח" מהבלוק אבל let לא?

- נציג קוד עם if (true) { var a = 1; let b = 2; } ואז console.log(a), console.log(b).

- נשאל: "שניהם הוכרזו באותו {} — אז למה אחד עובד ואחד זורק שגיאה?"

- **מהלך:** var מוגדר בסקופ הפונקציה כולה. let/const מוגדרים בסקופ הבלוק.

- המדריך יסכם: "זו הסיבה שקוד מודרני לא משתמש ב-var."
