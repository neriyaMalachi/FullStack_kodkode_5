## דגשים להעברת השיעור

- הבעיה קודם, בלי קוד — הסטודנטים צריכים לזהות בעצמם: "אין לי דרך להחליט" ו"אין לי דרך לחזור בלי להעתיק".

- Truthy/Falsy מוזכר בקצרה בלבד — מספיק שיזהו את חמשת ערכי ה-falsy.

- if/else if/else, ternary ו-switch כולם פותרים "אותה בעיה" בדרכים שונות.

- אל תיכנסו ל-switch עמוק — שלושה case מספיקים. הדגישו את break.

- שקף המערכים הוא preview מוצהר בלבד — מערכים ילמדו לעומק בשיעור נפרד.

- ודאו שכל סטודנט מבחין בין for (מספר איטרציות ידוע) ל-while (לא ידוע מראש).

## מושגים

- **תנאי (condition):** ביטוי שמוערך לאמת או שקר, וקובע אילו שורות קוד ירוצו.

- **Truthy / Falsy:** falsy: false, 0, "", null, undefined; כל השאר truthy.

- **if / else if / else:** הרצת בלוק קוד לפי תנאי, עם אפשרות לשרשר כמה תנאים.

- **אופרטור טרנרי (? :):** if/else מקוצר בשורה אחת.

- **switch / case:** השוואת ערך יחיד מול רשימת מקרים אפשריים; break עוצר, בלעדיו fall-through.

- **for:** לולאה עם מונה — for(init; condition; increment).

- **while:** לולאה שממשיכה כל עוד תנאי אמת.

- **for...of:** לולאה שעוברת על כל ערך ברשימה בלי לנהל אינדקס.

- **break / continue:** break עוצר ויוצא מהלולאה לגמרי; continue מדלג לאיטרציה הבאה בלבד.

## תרגיל חשיבה

- **נושא:** למה FizzBuzz צריך גם if/else וגם לולאה?

- נציג בלוק קוד עם לולאת for ריקה, ונשאל: "איך הופכים את זה לFizzBuzz?"

- נדגיש: חייבים לבדוק קודם את המקרה "מתחלק גם ב-3 וגם ב-5" לפני הבדיקות הנפרדות.

- **מהלך:** הצגת השלד, ניסיון ראשוני שגוי (סדר תנאים לא נכון), זיהוי הבאג ביחד, תיקון, הרצה.

- המדריך יראה בסוף: הלולאה קובעת כמה פעמים בודקים, וה-if/else קובע מה עושים בכל פעם.
