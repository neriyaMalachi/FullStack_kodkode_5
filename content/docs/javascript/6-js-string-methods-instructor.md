מטרת השיעור: הסטודנטים יבינו שמחרוזות ב-JavaScript הן Immutable — כל "שינוי" למעשה מחזיר מחרוזת חדשה — ויידעו לבחור את המתודה הנכונה לטיפול בטקסט.

בסוף השיעור הסטודנטים צריכים: להשתמש ב-slice, split, includes, trim, replace ו-toUpperCase עם הבנה מה כל אחת מחזירה, לזהות שתנאים שבודקים טקסט חייבים להיות מודעים ל-case ולרווחים, ולשלב Template Literals עם לוגיקה.

## דגשים להעברת השיעור

- הדגישו את Immutability בכל מתודה: "כתבו str.toUpperCase() — עכשיו הדפיסו את str. מה קרה?"

- trim — הסבירו בהקשר אמיתי: משתמש הקיש שם עם רווח בסוף, הולידציה נכשלה.

- split + join — הראו שזו שיטה נפוצה להמרת מחרוזת למערך ובחזרה.

- אל תכנסו ל-regex בשיעור הזה — replace עם מחרוזת פשוטה מספיק.

- Template Literals — תנו לסטודנטים לכתוב הודעת שגיאה דינמית אחת.

## מושגים

- **Immutable (בלתי ניתן לשינוי):** מחרוזות ב-JavaScript אינן ניתנות לשינוי — כל מתודה מחזירה ערך חדש.

- **slice(start, end):** חילוץ תת-מחרוזת לפי אינדקסים — מחזיר מחרוזת חדשה.

- **split(delimiter):** פיצול מחרוזת לפי תו מפריד — מחזיר מערך.

- **includes(substring):** בדיקה אם מחרוזת מכילה תת-מחרוזת — מחזיר boolean, תלוי רישיות.

- **trim():** הסרת רווחים לבנים מתחילת ומסוף המחרוזת.

- **replace(search, replacement):** החלפת מופע ראשון (עם מחרוזת) או כולם (עם regex).

- **toUpperCase / toLowerCase:** המרה לאותיות גדולות או קטנות.

- **Template Literal:** מחרוזת עם backtick שמאפשרת הכנסת ביטויים ישירות.
