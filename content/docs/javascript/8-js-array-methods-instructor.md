משך: 2 שעות אקדמיות (90 דקות).

מטרת השיעור: הסטודנטים יבינו למה forEach/map/filter/reduce/find קיימות — כל אחת פותרת בעיה קונקרטית עם לולאת for ידנית — וידעו לבחור את המתודה הנכונה ולשרשר אותן.

בסוף השיעור הסטודנטים צריכים: להסביר את ההבדל בין map (ממיר) ל-filter (מסנן) ל-reduce (מצמצם), לכתוב שרשור filter().map(), ולדעת מתי find מתאים יותר מ-filter.

דגש קריטי: לכל מתודה — קודם מראים את הכאב עם לולאת for ידנית, ורק אז את המתודה כפתרון ישיר. אל תהפכו את זה.

## דגשים להעברת השיעור

- שמרו על הסדר "בעיה → מתודה" בקפדנות.

- map תמיד מחזירה מערך באותו גודל — לכל אלמנט טרנספורמציה אחת, לא סינון.

- filter — המערך שיחזיר יכול להיות קטן יותר מהמקור, לעולם לא גדול יותר.

- find מול filter — find עוצר בפריט הראשון ומחזיר אותו (לא מערך); filter ממשיך ומחזיר מערך.

- reduce — הסבירו דרך "מצבר": מתחילים מערך התחלתי, מעדכנים ומחזירים אותו בכל פריט.

- שרשור — filter מחזיר מערך, ולכן אפשר לקרוא map מיד עליו.

## מושגים

- **map:** יוצר מערך חדש באותו גודל, תוצאת הפעלת ה-callback על כל אלמנט.

- **filter:** יוצר מערך חדש עם האלמנטים שעבורם ה-callback מחזיר true.

- **reduce:** מצמצם מערך לערך יחיד על ידי הצבר.

- **find:** מחזיר את האלמנט הראשון שעבורו ה-callback מחזיר true, או undefined.

- **findIndex:** מחזיר את האינדקס של האלמנט הראשון שנמצא, או -1.

- **forEach:** מפעיל callback על כל אלמנט; לא מחזיר מערך חדש.

- **Method Chaining:** קריאה לכמה מתודות בזו אחר זו.

## תרגיל חשיבה

- **נושא:** איזו מתודה מתאימה — map, filter, או reduce?

- נציג שלוש שאלות על מערך orders: "רק ההזמנות ששולמו", "רשימת מזהים בלבד", "הסכום הכולל".

- נשאל בכל שאלה: "מה סוג הפלט הצפוי — מערך מסונן, מערך ממופה, או ערך יחיד?"

- **מהלך:** דיון על כל שאלה, ניחוש, כתיבת הפתרון ביחד.

- המדריך יסכם: הפלט הצפוי הוא הרמז הראשון: מערך מסונן ← filter, מערך ממופה ← map, ערך יחיד ← reduce.
