## דגשים להעברת השיעור

- התחילו מהבעיה, לא מההגדרה — הראו את 4 המשתנים הנפרדים לפני שמזכירים "Object".

- dot notation מול bracket notation — dot לא יכולה לקבל משתנה כשם תכונה, רק שם קבוע.

- Objects מקוננים — קשרו ישירות לבעיית הפתיחה: הימנעות מ-userAddressCity נפרד.

- const ואובייקטים — האובייקט עצמו ניתן לשינוי גם כשהוא מוגדר עם const.

- method ו-this — הראו פונקציה "רגילה" שלא יודעת על איזה Object היא פועלת, ואז this כפתרון.

## מושגים

- **Object:** אוסף של זוגות מפתח-ערך (key-value). מאחד נתונים קשורים תחת ישות אחת.

- **Property (תכונה):** זוג key-value בודד בתוך Object. המפתח הוא תמיד מחרוזת.

- **Dot Notation:** גישה לתכונה עם נקודה — user.name.

- **Bracket Notation:** גישה לתכונה עם סוגריים מרובעות — user["name"]. הכרחי כששם התכונה דינמי.

- **Nested Object:** תכונה שערכה הוא בעצמו Object.

- **Method (מתודה):** תכונה שערכה הוא פונקציה.

- **this:** בתוך מתודה, מצביע על ה-Object שדרכו נקראה המתודה.

## תרגיל חשיבה

- **נושא:** אותה מתודה, מופעים שונים — למה this בכלל נחוץ?

- נציג שתי Objects דומות: circle1 = { radius: 5, area() {...} } ו-circle2 = { radius: 10, area() {...} }.

- נשאל: "אם כותבים את area() פעם אחת בלי this — על איזה radius היא תדע לפעול?"

- **מהלך:** הצגת הבעיה, ניחוש מנומק, הרצת קוד ללא this, הרצה עם this (עובד לשני המעגלים).

- המרצה יסביר ש-this הוא הדרך של JavaScript לתת למתודה אחת "לדעת" באיזה Object היא פועלת כרגע.
