## מה זה?

Docker הוא כלי שמאפשר לארוז אפליקציה יחד עם כל מה שהיא צריכה כדי לרוץ — קוד, תלויות, גרסת שפה — לתוך "קונטיינר" אחיד שרץ באותה צורה בדיוק על כל מחשב. הבעיה שהוא פותר מוכרת לכל מפתח: "אצלי זה עובד" הופך לבעיה כשהקוד עובר למחשב אחר או לשרת ייצור. בקטגוריה הזו לומדים איך לבנות קונטיינרים לאפליקציית Node/Express, ואיך להריץ כמה שירותים ביחד (שרת + בסיס נתונים) בעזרת כלי אחד.

## מה הולכים ללמוד

- **Docker Basics** — מהם קונטיינרים ואימג'ים, ואיך מריצים ומנהלים אותם
- **Dockerfile** — איך מגדירים בקובץ אחד את כל השלבים לבניית אימג' לאפליקציה שלנו
- **docker-compose** — איך מגדירים ומריצים כמה קונטיינרים יחד (למשל שרת ובסיס נתונים) בפקודה אחת
- פרויקט מסכם — בניית Dockerfile רב-שלבי (multi-stage) יחד עם docker-compose שמריץ גם בסיס נתונים, כולל הגדרת קונפיגורציה דרך קובץ .env

## למה זה חשוב

Docker הוא הסטנדרט התעשייתי להרצה ופריסה (deployment) של אפליקציות web היום — כמעט כל צוות פיתוח משתמש בו כדי לוודא שסביבת הפיתוח, הבדיקות והפרודקשן זהות. שליטה בדוקר מאפשרת להריץ פרויקט שלם עם כל התלויות שלו בפקודה אחת, לשתף סביבת פיתוח עם שאר הצוות בלי "אצלי זה עובד", ולהתקדם בביטחון לעבר נושאים כמו CI/CD ופריסה בענן. זהו כישור שכמעט כל משרת Backend או DevOps מצפה שמפתח יכיר ברמה כלשהי.
