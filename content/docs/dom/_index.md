## מה זה?

ה-DOM (Document Object Model) הוא הדרך שבה JavaScript "רואה" ונוגע בעמוד HTML שכבר נטען בדפדפן. בלי DOM, עמוד ווב הוא סטטי — מה שנכתב ב-HTML הוא מה שהמשתמש רואה, נקודה. עם DOM, אפשר לשנות תוכן, להגיב ללחיצות ולקלט מהמשתמש, וליצור עמודים שמתעדכנים בזמן אמת בלי לרענן את הדף. זו הקטגוריה שבה JavaScript הופך מסקריפט מבודד לכלי שבאמת שולט בחוויית המשתמש.

## מה הולכים ללמוד

- **DOM Intro** — מהו ה-DOM ואיך JavaScript מתחבר לעמוד HTML שכבר נטען
- **Selecting elements** — איך מוצאים אלמנטים ספציפיים בעמוד כדי לעבוד איתם
- **Events** — איך מגיבים ללחיצות, הקלדה ופעולות אחרות של המשתמש
- **Content manipulation** — איך משנים טקסט ותוכן של אלמנטים קיימים באופן דינמי
- **classList & styling** — איך משנים מחלקות CSS ועיצוב של אלמנטים ישירות מהקוד
- **Creating/Removing elements** — איך מוסיפים ומסירים אלמנטים מהעמוד בזמן ריצה
- **Traversing the DOM** — איך נעים בין אלמנטים לפי הקשרים ביניהם (הורה, ילד, אח)
- **Forms** — איך קוראים ומאמתים קלט שמשתמש מזין בטופס
- **Event Delegation** — איך מטפלים ביעילות באירועים על הרבה אלמנטים בלי צורך להצמיד מאזין לכל אחד
- **LocalStorage** — איך שומרים מידע בדפדפן כך שהוא נשאר גם אחרי רענון העמוד
- פרויקט Todo app — בניית אפליקציית משימות שמשלבת אירועים, יצירת אלמנטים ו-LocalStorage
- פרויקט Notes app — בניית אפליקציית פתקים נוספת שמתרגלת את אותם עקרונות במבנה שונה

## למה זה חשוב

זו הקטגוריה שבה עמוד ווב "מתעורר לחיים" — במקום דף סטטי, בונים ממשק שמגיב למשתמש בזמן אמת, בדיוק כמו כל אתר או אפליקציית ווב שמכירים. השליטה ב-DOM היא הבסיס לכל עבודה עם JavaScript בצד הלקוח, והיא גם התשתית המושגית שעליה בנויות ספריות כמו React — גם שם, מתחת למנוע, בסופו של דבר משנים DOM. מי שמבין DOM לעומק מבין למה React בכלל נחוץ ומה הוא פותר.
