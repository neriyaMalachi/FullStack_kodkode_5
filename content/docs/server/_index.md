## מה זה?

אם JavaScript היא השפה, אז הקטגוריה הזו היא המקום שבו היא עוברת מהדפדפן לצד השרת: כאן לומדים איך לבנות את החלק שמריץ את הלוגיקה העסקית, שומר נתונים ועונה לבקשות מכל לקוח - דפדפן, אפליקציית מובייל או שירות אחר. מתחילים מהבסיס - איך פרוטוקול HTTP עובד בכלל ואיך בונים שרת גולמי עם Node.js בלי שום ספרייה - ואז עוברים ל-Express, ה-Framework הנפוץ ביותר לבניית שרתים ב-Node, שהופך את אותן משימות לפשוטות ומאורגנות בהרבה. הקטגוריה בנויה על היסודות שנלמדו ב-JavaScript, ובמיוחד על ההבנה של קוד א-סינכרוני.

## מה הולכים ללמוד

- להבין את יסודות פרוטוקול HTTP - בקשות, תשובות וקודי סטטוס
- להכיר את סביבת הריצה של Node.js ומה מייחד אותה
- לבנות שרת HTTP גולמי בלי שום Framework
- לקרוא פרמטרים מתוך כתובת ה-URL
- לפענח ולעבד גוף בקשה (Request Body) שמגיע מהלקוח
- להכיר את Express ואיך הוא מפשט בניית שרתים
- לטפל בגוף הבקשה ב-Express בצורה מסודרת
- לעבוד עם פרמטרים ומחרוזות שאילתה (Query) בבקשות
- לארגן נתיבים בעזרת Router כדי לשמור על קוד מסודר וניתן להרחבה
- להשתמש ב-Middleware כדי להריץ לוגיקה משותפת על בקשות
- לטפל בשגיאות בצורה נכונה, גם בשרת גולמי וגם ב-Express
- לנהל משתני סביבה ומידע רגיש בעזרת dotenv
- לתכנן API בסגנון REST בצורה ברורה ועקבית
- פרויקט מסכם: בניית REST API מלא לניהול משימות (Task Manager)

## למה זה חשוב

כל אפליקציית ווב אמיתית - כולל כל מה שתבנו ב-React בהמשך הקורס - זקוקה לשרת שמנהל נתונים, מאמת משתמשים ומחליט מה מותר ומה אסור. הקטגוריה הזו נותנת לכם את הידע לבנות את החלק הזה בעצמכם, מהיסודות הגולמיים ועד ל-API מקצועי ב-Express, ובכך משלימה אתכם למפתחי Full Stack של ממש - לא רק מי שיודע לבנות ממשק, אלא מי שיודע גם מה קורה "מאחורי הקלעים" כשלוחצים על כפתור.
