## מה זה?

TypeScript היא שכבה שנוספת מעל JavaScript ומוסיפה לה טיפוסים (Types) - כלומר, הגדרה מפורשת של איזה סוג מידע כל משתנה, פרמטר או ערך מוחזר אמור להכיל. במקום לגלות טעויות רק בזמן הרצה, TypeScript מזהה אותן כבר בזמן הכתיבה, לפני שהקוד בכלל רץ. הקטגוריה נותנת מבוא ממוקד לרעיון של Static Typing, לתחביר הבסיסי של טיפוסים וממשקים (Interfaces), ולדרך שבה כל זה עוזר לכתוב קוד JavaScript אמין יותר.

## מה הולכים ללמוד

- להכיר את הרעיון של Static Typing ואיך הוא שונה מ-JavaScript רגיל, כולל טיפוסים בסיסיים וממשקים (Interfaces)
- פרויקט מסכם: המרת פרויקט JavaScript קיים ל-TypeScript

## למה זה חשוב

ככל שפרויקט גדל, קל יותר לטעות - לשכוח לבדוק אם ערך קיים, להעביר פרמטר מהסוג הלא נכון, או לשנות קוד במקום אחד ולשבור מקום אחר בלי לשים לב. TypeScript תופסת חלק גדול מהטעויות האלה כבר בזמן הכתיבה, ולכן היא נפוצה מאוד בפרויקטים מקצועיים, כולל פרויקטי React ו-Node בקנה מידה גדול. גם היכרות בסיסית עם TypeScript, כפי שנלמדת כאן, נותנת לכם יתרון משמעותי - היכולת לקרוא ולהבין קוד שכתוב בה, ולהתחיל להשתמש בה בעצמכם כשתרצו קוד בטוח ואמין יותר.
