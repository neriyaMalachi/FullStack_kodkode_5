## מה זה?

CSS היא השפה שהופכת דף HTML יבש לעמוד שנראה ומרגיש כמו אתר אמיתי — צבעים, מרווחים, פריסה, והתאמה לכל גודל מסך. בלי CSS כל אתר היה נראה כמו מסמך טקסט פשוט; איתו אפשר לבנות כל פריסה שרואים ברשת, מדף נחיתה פשוט ועד אפליקציית ווב מורכבת. בקטגוריה הזו לומדים לא רק "איך לצבוע דברים", אלא איך לחשוב על פריסה — איך אלמנטים תופסים מקום, איך הם מתייחסים אחד לשני, ואיך העמוד מגיב לשינויי גודל מסך.

## מה הולכים ללמוד

- **Selectors** — איך לבחור בדיוק את האלמנטים שרוצים לעצב מתוך העמוד
- **Box Model & Units** — איך כל אלמנט תופס מקום (padding, border, margin) ובאילו יחידות מודדים גדלים
- **Specificity** — איך הדפדפן מחליט איזה כלל CSS מנצח כשיש כמה כללים מתנגשים
- **Pseudo-selectors** — איך לעצב מצבים כמו hover, focus או איברים ראשונים/אחרונים בלי JavaScript
- **CSS Variables** — איך שומרים ערכים חוזרים (צבעים, מרווחים) במקום אחד ומשתמשים בהם בכל הקובץ
- **Position** — איך לשלוט במיקום מדויק של אלמנטים ביחס לעמוד או לאלמנט אחר
- **Flexbox** — איך מסדרים אלמנטים בשורה או בעמודה בצורה גמישה ומרוכזת
- **Grid** — איך בונים פריסות דו-ממדיות מורכבות בקלות יחסית
- **Responsive design (media queries)** — איך גורמים לעמוד להיראות טוב גם בנייד וגם במסך גדול
- **Transitions & Animations** — איך מוסיפים תנועה חלקה ואפקטים שמשפרים את חוויית המשתמש
- פרויקט מסכם — עיצוב עמוד מתכון שלם מהאפס באמצעות כל הכלים שנלמדו

## למה זה חשוב

כל אתר שבונים, גם עם התוכן והפונקציונליות הכי טובים, ייכשל אם הוא לא נראה טוב ולא נוח לשימוש — ו-CSS הוא הכלי שאחראי בדיוק על זה. שליטה טובה ב-CSS מאפשרת להפוך תכנון (design) לעמוד עובד, לבנות ממשקים שמסתגלים לכל מכשיר, ולעבוד בשיתוף פעולה עם מעצבי UI/UX בצורה חלקה. זהו כישור שנדרש בכל תפקיד Frontend, ורוב הזמן שמפתחים חדשים מבלים בפועל הוא בדיוק בסידור ותיקון פריסות.
