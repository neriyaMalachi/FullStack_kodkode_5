## מה זה?

הקטגוריה הזו סוגרת את המעגל בין React לבין שרת אמיתי - זה השלב שבו אפליקציית React שבניתם מפסיקה להיות אוסף קומפוננטות יפות ומתחילה לדבר עם עולם אמיתי: שרתים, נתוני משתמשים, הרשאות ותקשורת בזמן אמת. הנחת היסוד היא שכבר יש לכם בסיס ב-React ובשרת (Express) מקטגוריות קודמות, וכאן לומדים איך לחבר בין השניים בפועל, לשמור על אבטחה בסיסית, ולהעלות את המערכת לאוויר כך שמשתמשים אמיתיים יוכלו להשתמש בה.

## מה הולכים ללמוד

- להשוות בין Fetch ל-Axios ולבחור את הכלי הנכון לתקשורת עם שרת
- לבנות תהליך הזדהות (Auth) מלא בצד הלקוח, כולל עבודה עם JWT
- לפרוס (Deploy) אפליקציית React יחד עם שרת לסביבת ייצור
- להשתמש ב-WebSockets לתקשורת דו-כיוונית בזמן אמת
- פרויקט מסכם: בניית אפליקציית צ'אט בזמן אמת שמשלבת את כל מה שנלמד בקטגוריה

## למה זה חשוב

זו בדיוק הנקודה שבה "פרויקט לימודי" הופך ל"מוצר אמיתי": חיבור אמין לשרת, הזדהות מאובטחת ופריסה תקינה הם מה שמפריד בין אפליקציה שרצה רק על המחשב שלכם לבין אחת שמשתמשים אמיתיים יכולים להיכנס אליה. היכולת לעבוד עם WebSockets פותחת דלת לעולם שלם של אפליקציות אינטראקטיביות - צ'אטים, התראות בזמן אמת, לוחות שיתופיים - שהם חלק בלתי נפרד מפיתוח ווב מודרני. מי שמשלים את הקטגוריה הזו יודע לקחת אפליקציית Full Stack מהמסך שלו ולהוציא אותה החוצה לעולם.
