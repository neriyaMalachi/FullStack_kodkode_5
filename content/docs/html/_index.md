## מה זה?

HTML הוא שלד כל עמוד באינטרנט — השפה שמגדירה אילו אלמנטים קיימים בעמוד ומה המשמעות שלהם: כותרת, פסקה, תמונה, טופס. בלי HTML, אין עמוד ווב בכלל — הוא הבסיס שעליו נבנים אחר כך CSS לעיצוב ו-JavaScript לאינטראקטיביות. בקטגוריה הזו לומדים לכתוב HTML נכון וסמנטי, כלומר כזה שמתאר את המשמעות האמיתית של כל חלק בעמוד, ולא רק את המראה שלו.

## מה הולכים ללמוד

- **HTML Basics** — המבנה הבסיסי של מסמך HTML והתגיות (tags) הנפוצות ביותר
- **Semantic tags** — איך בוחרים תגית שמתארת נכון את התפקיד של כל חלק בעמוד (כמו header, nav, article)
- **Images & Media** — איך משלבים תמונות ומדיה בעמוד בצורה נכונה ונגישה
- **Tables** — איך בונים טבלאות להצגת מידע מובנה
- **Forms** — איך בונים טפסים לקליטת קלט מהמשתמש
- פרויקט מסכם — בניית עמוד מתכון סמנטי ונגיש במלואו, בלי CSS או JavaScript בשלב הזה

## למה זה חשוב

HTML סמנטי הוא לא רק "כללי כתיבה יפים" — הוא משפיע ישירות על נגישות האתר לאנשים עם מוגבלויות, על הדירוג שלו במנועי חיפוש (SEO), ועל הקלות שבה כל מפתח אחר יכול להבין את הקוד. כל טכנולוגיית Frontend שתלמדו אחר כך — CSS, JavaScript, React — פועלת מעל שלד ה-HTML הזה, כך שיסודות חזקים כאן חוסכים המון כאב ראש בהמשך. זהו הצעד הראשון וההכרחי בדרך להיות מפתח Frontend או Fullstack.
