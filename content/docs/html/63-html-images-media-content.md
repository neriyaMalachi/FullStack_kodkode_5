## מה זה?

עד עכשיו כל התוכן שלנו היה טקסט. אבל רוב האתרים כוללים תמונות, ולפעמים וידאו או אודיו. HTML נותן תגיות ייעודיות לכל אחד מהם: `<img>` לתמונות, `<video>` לוידאו, `<audio>` לאודיו — כל אחת עם תכונות (Attributes) משלה שקובעות איך התוכן נטען ומוצג.

## מילות מפתח שחשוב לזכור

• `<img src="..." alt="...">` — מטמיע תמונה; `src` הוא הכתובת/נתיב, `alt` הוא תיאור טקסטואלי (חובה!)

• `alt` (alternative text) — טקסט שמוצג אם התמונה לא נטענת, ושקוראי מסך מקריאים למשתמשים עיוורים — **לא אופציונלי**

• `<video>` / `<audio>` — מטמיעים וידאו/אודיו, עם תכונת `controls` שמוסיפה כפתורי הפעלה/עצירה

• Responsive Image (תמונה רספונסיבית) — תמונה שמתאימה את גודלה למסך המכשיר, בעזרת CSS (ביחידת CSS הבאה) או `srcset`

• Lazy Loading — `loading="lazy"` — דוחה טעינת תמונה עד שהיא קרובה להיכנס למסך, לביצועים טובים יותר בעמודים עם הרבה תמונות

```html
<img src="cat.jpg" alt="An orange cat sleeping on a couch" loading="lazy" />

<video src="intro.mp4" controls width="480"></video>

<audio src="podcast.mp3" controls></audio>
```

## הסבר עיקרי

alt הוא לא קישוט — הוא נגישות אמיתית — קורא מסך למשתמש עיוור **מקריא** את ה-`alt` במקום התמונה עצמה — בלעדיו, המשתמש פשוט "מפספס" את התוכן החזותי לגמרי. גם למשתמשים רואים: אם התמונה לא נטענת (בעיית רשת, קישור שבור), `alt` מוצג כטקסט חלופי במקומה. `alt=""` (ריק) תקין רק לתמונות **דקורטיביות בלבד** (לא נושאות מידע) — אחרת, `alt` תמיד צריך לתאר את התוכן.

controls כברירת מחדל חובה — בלי `controls` על `<video>`/`<audio>`, למשתמש **אין דרך** להפעיל/לעצור/לכוון עוצמה — התג פשוט "יושב" בעמוד בלי שום ממשק. `controls` מוסיף את סרגל הכלים הסטנדרטי של הדפדפן.

Lazy Loading חוסך זמן טעינה — עמוד עם 50 תמונות לא צריך לטעון את **כולן** מיד — `loading="lazy"` אומר לדפדפן "טען את התמונה הזו רק כשהמשתמש כמעט גולל אליה" — משפר משמעותית את זמן הטעינה הראשוני של העמוד.

## יתרונות

תמיכה מובנית בדפדפן, בלי JavaScript נדרש להצגה בסיסית; `alt` נותן נגישות ו-fallback באותה תכונה אחת; `loading="lazy"` משפר ביצועים בקלות, בלי מאמץ נוסף.

## חסרונות

פורמטים/קידודים שונים של וידאו/אודיו לא תמיד נתמכים בכל דפדפן; תמונות גדולות מדי בלי אופטימיזציה עדיין פוגעות בביצועים, גם עם `lazy`; `alt` גרוע (או ריק כשלא צריך) מבטל את יתרון הנגישות.

## נקודות חשובות

• `alt` הוא Attribute חובה על `<img>` — קריטי לנגישות ול-fallback

• `controls` נדרש על `<video>`/`<audio>` כדי לתת למשתמש ממשק הפעלה

• `loading="lazy"` דוחה טעינת תמונות רחוקות מהמסך, לביצועים

• `alt=""` (ריק) תקין רק לתמונות דקורטיביות טהורות, לא לתמונות עם מידע

## טעויות נפוצות

• שכחת `alt` לגמרי, או מילוי אותו בטקסט לא-מתאר ("image1") — לא נותן שום מידע אמיתי

• שכחת `controls` על `<video>`/`<audio>` — המשתמש לא יכול להפעיל בכלל

• הטמעת תמונות ענקיות (רזולוציה גבוהה מדי) בלי אופטימיזציה — מאיטה טעינת עמוד משמעותית

## סיכום

`<img>`, `<video>`, `<audio>` מטמיעים מדיה בעמוד. `alt` על `<img>` הוא לא-אופציונלי — קריטי לנגישות ול-fallback כשתמונה לא נטענת. `controls` נדרש כדי לתת למשתמש ממשק הפעלה על מדיה. `loading="lazy"` דוחה טעינת תמונות רחוקות למסך, לביצועים טובים יותר.

## תרגילים

### תרגיל 1 — img עם alt תקין

**המשימה:** הוסיפו לעמוד תמונה עם `alt` שמתאר אותה במדויק (לא "image" גנרי).

**בדיקה:** שינוי ה-`src` לנתיב שגוי בכוונה מציג את טקסט ה-`alt` במקום התמונה.

### תרגיל 2 — video עם controls

**המשימה:** הטמיעו וידאו קצר עם `controls`.

**בדיקה:** מוצג סרגל כלים (play/pause/עוצמה) מתחת לוידאו, שאפשר להפעיל בעכבר.

### תרגיל 3 — lazy loading

**המשימה:** הוסיפו `loading="lazy"` לתמונה שממוקמת רחוק מתחילת העמוד (למשל, אחרי הרבה תוכן/פסקאות).

**בדיקה:** ב-DevTools (Network tab), התמונה לא מופיעה ברשימת הבקשות עד שגוללים קרוב אליה.

## פרויקט מסכם

**המשימה:** הוסיפו גלריית תמונות לעמוד ה-"אודות" מהפרויקטים הקודמים.

**דרישות:**
1. לפחות 3 תמונות, כל אחת עם `alt` תיאורי ומדויק
2. תמונה אחת (הראשונה, למעלה) בלי `lazy`; שאר התמונות עם `loading="lazy"`
3. אם רלוונטי — הוסיפו וידאו קצר (או קישור embed) עם `controls`

**בדיקה:** כל תמונה מציגה `alt` הגיוני אם משנים בכוונה את ה-`src` לנתיב שגוי; ב-Network tab, רק התמונה הראשונה נטענת מיד בטעינת העמוד.
