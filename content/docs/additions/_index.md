## מה זה?

בקטגוריה הזו הופכים שרת Node/Express שעובד "אצלי במחשב" לשרת שאפשר באמת להריץ בפרודקשן. אחרי שכבר יודעים לבנות API עם ראוטים, בקרים ובסיס נתונים, השלב הבא הוא להקשיח אותו — לוודא שהוא רושם מה קורה בו, דוחה קלט לא תקין, לא חשוף לפרצות אבטחה נפוצות, מזהה מי פונה אליו, ובנוי בצורה מסודרת שקל לתחזק. אלו לא "תוספות יוקרה" אלא הדברים שמפרידים בין פרויקט לימודי לשרת אמיתי.

## מה הולכים ללמוד

- **Logging** — איך לתעד מה קורה בשרת בזמן אמת, כדי לדעת לאבחן תקלות בלי לנחש
- **Validation with Zod** — איך לוודא שכל קלט שמגיע מהלקוח תקין לפני שהוא נוגע בלוגיקה העסקית
- **OWASP security basics** — הכרת פרצות האבטחה הנפוצות ביותר בשרתי web ואיך נמנעים מהן
- **JWT authentication** — איך מזהים משתמש מחובר ומגנים על ראוטים שדורשים הרשאה
- **MVC/DDD architecture** — איך מארגנים פרויקט גדל בצורה שנשארת קריאה וניתנת להרחבה
- פרויקט מסכם — הקשחת API קיים לניהול משימות (Task Manager) לרמת פרודקשן, תוך שילוב כל הנושאים יחד

## למה זה חשוב

שרת ללא לוגים, ולידציה ואבטחה עלול לעבוד מצוין בדמו ולקרוס — או להיפרץ — ברגע שהוא נתקל בעולם האמיתי. הנושאים בקטגוריה הזו הם בדיוק מה שמבדיל מפתח ג'וניור ממפתח שיודע לשלוח קוד לפרודקשן בביטחון: יכולת לאבחן תקלות, להגן על המידע של המשתמשים, ולבנות קוד שצוות שלם יכול לעבוד עליו לאורך זמן. אלו כישורים שנבדקים ישירות בראיונות עבודה ונדרשים כמעט בכל תפקיד Backend אמיתי.
